- Crystal Frequency: 11.0592 MHz
- Software: Keil µVision
- Output: LED / Digital Output

**TASK NO:** CAT5B – Software PWM Generation

## OBJECTIVE

- Generate PWM signals using software.
- Control LED brightness by varying the duty cycle.
- Fade the LED from 0% to 100% brightness and back to 0%.
- Generate a square wave with variable frequency.

## CORE LOGIC

1. Configure the required microcontroller GPIO pins.
2. Generate a software PWM signal using timed HIGH and LOW intervals.
3. Gradually increase the duty cycle from 0% to 100%.
4. Gradually decrease the duty cycle from 100% to 0%.
5. Repeat the fading sequence continuously.
6. Generate a square wave by periodically toggling a digital output pin.
7. Vary the delay between transitions to change the square-wave frequency.

## INFERENCE

Software PWM was implemented using the AT89S52 microcontroller. LED brightness was controlled by varying the duty cycle, producing a fading effect. A variable-frequency square wave was also generated by changing the output toggling interval.
